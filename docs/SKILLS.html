CoreGuard · Agent skills

Procedures an agent can load, not improvise.

72 skills that turn the 99-tool Agent Commerce MCP server into repeatable, auditable procedures: bind an approval, vet a server before install, triage poisoned metadata, freeze an agent, prove a receipt later. Every skill is a folder with a SKILL.md; every tool it names is one the server actually exposes.

offline · deterministic zero keys VERIFIED ≠ SAFE tool reference docs

Install in one copy.

Skills are plain folders. Copy the set into your runtime's skills directory, or take a single skill with the command on its card below — no clone, no keys. The server is registered once.

mkdir -p .claude/skills && cp -r skills/* .claude/skills/
# mcp client config
{"mcpServers":{"coreguard":{"command":"npx","args":["-y","@coreguard/agent-commerce@0.5.0"]}}}
No skill here claims a tool is safe, a merchant honest or a payment settled, and nothing on this page is adoption evidence: no install count, user count, review or endorsement is claimed anywhere. Each skill ends with the boundary it cannot cross, and each card's byte count and digest are read from the file itself.

The 72 skills.

Each card links to its SKILL.md and to the tools it calls. The chips are generated from the file's own text, so a skill that names a missing tool fails the build instead of shipping.
