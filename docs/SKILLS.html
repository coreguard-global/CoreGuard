CoreGuard · Agent skills

Procedures an agent can load, not improvise.

10 skills that turn the 46-tool Agent Commerce MCP server into repeatable, auditable procedures: bind an approval, vet a server before install, triage poisoned metadata, freeze an agent, prove a receipt later. Every skill is a folder with a SKILL.md; every tool it names is one the server actually exposes.

offline · deterministic zero keys VERIFIED ≠ SAFE tool reference docs

Install in one copy.

Skills are plain folders. Copy the set into your runtime's skills directory, or point the runtime at this folder. The server is registered once.

mkdir -p .claude/skills && cp -r skills/* .claude/skills/
# mcp client config
{"mcpServers":{"coreguard":{"command":"npx","args":["-y","@coreguard/agent-commerce@0.2.0"]}}}
No skill here claims a tool is safe, a merchant honest or a payment settled. Each one ends with the boundary it cannot cross.

Each card links to its SKILL.md and to the tools it calls. The chips are generated from the file's own text, so a skill that names a missing tool fails the build instead of shipping.
