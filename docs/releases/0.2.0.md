# 0.2.0 — Wave 3 (46 tools) and ten agent skills

`@coreguard/agent-commerce@0.2.0` adds twenty deterministic MCP tools and a
ten-skill pack. The consent/verification core, the transport, the error contract
and the boundaries are unchanged: offline, zero keys, no wall clock inside a
commitment, `VERIFIED ≠ SAFE`.

## Added — Wave 3 (CG-W3/1)

**Policy reasoning**

- `coreguard_compile_policy` — compact spend spec → canonical CGEP/1 policy + stable digest.
- `coreguard_explain_decision` — per-rule checks and the smallest single change that clears the first block.
- `coreguard_simulate_spend` — dry-run a batch; no approval, counter or ledger write.
- `coreguard_diff_policies` — rule-level diff, limit delta, strictness, re-consent flag.
- `coreguard_generate_boundary_cases` — at/±1 limit, unlisted target/recipient, closed window, wrong currency.

**MCP supply chain**

- `coreguard_audit_server_manifest` — risk card for a third-party `server.json`.
- `coreguard_scan_tool_descriptions` — bidi/tag/zero-width characters, HTML comments, imperative payloads, with offsets.
- `coreguard_check_lookalike` — confusable folding, mixed-script and punycode signals.
- `coreguard_diff_tool_surface` — rug-pull diff between two `tools/list` snapshots.
- `coreguard_verify_evidence_bundle` — recompute bundle and item digests offline.

**Evidence**

- `coreguard_redact_receipt` — redacted copy + manifest + both digests.
- `coreguard_attest_batch` — Merkle root and per-item inclusion proofs.
- `coreguard_verify_batch_proof` — offline inclusion verification.

**Operations**

- `coreguard_freeze_agent` — revoke an agent and reject its open approvals in one audited operation.
- `coreguard_budget_runway` — straight-line runway and exhaustion epoch from pinned inputs.
- `coreguard_detect_spend_anomaly` — median/MAD outlier scan with an explicit threshold.
- `coreguard_incident_timeline` — sequence-ordered ledger events, gaps, chain status.

**Interop and meta**

- `coreguard_translate_receipt` — structural ACP/x402/CGCR mapping with a loss list.
- `coreguard_emit_test_vectors` — integration vectors with engine-computed verdicts.
- `coreguard_describe_surface` — capability card or badge a directory can quote verbatim.

## Boundaries

Wave 3 is arithmetic over caller-supplied JSON. The manifest and description
audits are structural — they do not execute the audited server. Findings are
evidence for a human decision, not verdicts on a third party. No payment
network, chain, merchant or provider is contacted.
