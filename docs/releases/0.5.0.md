# @coreguard/agent-commerce 0.5.0

**Status:** published 2026-11-26 through the gated release workflow (run `45838608694`, `confirm=RELEASE`) on squash commit `a4be51d8`. npm `latest` = `0.5.0`; MCP Registry `io.github.EslaM-X/coreguard-agent-commerce@0.5.0` is active and `isLatest`.

## Summary

Stellar Agent Gate (CG-SG/1) adds 5 deterministic, offline MCP tools for agent-initiated Stellar actions: pre-execution policy/refusal decisions, binding an ALLOW decision to exact XDR envelope bytes, verifying caller-supplied submission evidence, exporting a redacted evidence pack and listing named adversarial vectors. The MCP surface grows from 94 to **99 tools**; the skill library stays at **72 skills**.

## Added

- `coreguard_preflight_stellar_agent_payment`: canonicalizes the proposed Stellar action, checks policy allowlists, amount ceiling, replay nonce, authority scopes, pinned time bounds and envelope projection; fails closed with named refusal codes.
- `coreguard_bind_stellar_authorization`: binds an ALLOW decision to the exact envelope bytes and the observed operation projection; refuses byte drift and named field drift; never signs or submits.
- `coreguard_verify_stellar_submission_evidence`: verifies caller-supplied submission evidence against a BOUND authorization; `VERIFIED` means saved bytes and named fields agreed, not settlement finality.
- `coreguard_export_stellar_evidence_pack`: exports a redacted, digest-rooted pack for human review; nothing is transmitted.
- `coreguard_stellar_adversarial_vectors`: exposes 16 named deterministic cases (amount escalation, substitution, replay, overreach, byte drift, failed result, missing evidence and others).
- `docs/COREGUARD-STELLAR-AGENT-SECURITY-SPEC-v0.2.md`: P1 gate specification, refusal taxonomy, evidence schema and named adversarial vectors.
- `scripts/stellar-testnet-proof.mjs`: optional, manual, real Testnet proof script. It is not part of `npm test`; the recorded 2026-11-26 run states its ephemeral keys, endpoint, hash and boundaries honestly in `docs/STELLAR-TESTNET-PROOF-2026-11-26.md`.

## Boundaries

- CG-SG/1 is offline and deterministic. It makes no Stellar RPC, Horizon, Friendbot, wallet, network, bank or external call.
- It does not sign, submit, custody keys, check balances, resolve addresses, clear sanctions, perform KYC/AML or settle money.
- `VERIFIED ≠ SAFE`. No settlement finality, sanctions clearance, KYC/AML approval, asset truth, model correctness or compliance certification is claimed.
- No customer, pilot, sponsor, audit, funding, partnership, endorsement, adoption or signed-in third-party MCP client `RUN-BY-HAND` is claimed by this preparation.
- `ops/production` remains `INTEGRATION_READY, NOT_PROVISIONED`.
