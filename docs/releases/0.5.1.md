# @coreguard/agent-commerce 0.5.1

**Status:** prepared in the repository. The published npm `latest` remains `0.5.0` until the gated release workflow runs with `confirm=RELEASE`; this document records what changed and how it was verified, and is updated with the run id only after that run exists.

## Summary

Wave 6 (CG-W6/1) adds **20 deterministic, offline Stellar smart-account and session-key tools**. The MCP surface grows from **99 to 119 tools**; the skill library grows from **72 to 92 skills**. Nothing is signed, submitted or broadcast, and no Stellar RPC/Horizon/Soroban call is made.

The wave targets the concrete failure mode of an agent holding a scoped Stellar key: it can be *inside* its policy and still pay the wrong issuer, the wrong memo, an expired envelope, an over-broad SAC allowance, or replay a sequence. Each tool answers one of those questions with named checks.

## Boundaries

- Wave 6 is offline and deterministic. It makes no Stellar RPC, Horizon, Soroban, anchor, DEX, wallet or network call, and it never signs, submits or broadcasts.
- `VERIFIED ≠ SAFE`. A PASS means the supplied evidence matched the supplied policy; it is not settlement finality, asset truth, counterparty honesty, KYC/AML clearance or a compliance certification.
- No customer, pilot, sponsor, audit, funding, partnership, endorsement, adoption or third-party signed-in MCP client run is claimed.
- `ops/production` remains `INTEGRATION_READY, NOT_PROVISIONED`.
