# @coreguard/agent-commerce 0.1.5

## What changed

- **Published tarball now includes `server.json`**. The MCP registry manifest is part of the npm package files, and `scripts/publish-check.mjs` fails closed if `server.json` is missing, malformed, or version-mismatched with `package.json`.
- **MCP registry publishing is automated in the release workflow**. After a successful npm publish, `.github/workflows/release.yml` verifies the published npm version, downloads and Sigstore-verifies `mcp-publisher`, authenticates with GitHub OIDC, and publishes `packages/agent-commerce/server.json`.
- **No new MCP registry secret is required.** The workflow uses GitHub OIDC (`id-token: write`). The only repository/environment secret required by the release workflow remains `NPM_TOKEN`.

## Verification

- `npm pack --dry-run` for `packages/agent-commerce` includes `server.json`.
- `server.json` version and `packages[0].version` match `package.json` version `0.1.5`.
- MCP registry listing should report `@coreguard/agent-commerce@0.1.5` after the release workflow completes.
