# @coreguard/agent-commerce 0.3.0

**Status:** published 2026-11-25 through the gated release workflow (run `45688325860`, `confirm=RELEASE`). npm `latest` = `0.3.0`; MCP Registry `io.github.EslaM-X/coreguard-agent-commerce@0.3.0` is active and `isLatest`.

## Summary
Wave 4 (CG-W4/1) adds 24 deterministic, offline MCP tools for evidence-first verification across cross-border payments, chain settlement evidence, machine/robot commerce, credit/loan evidence, and incident operations. The skill library grows to 40 skills.

## Added
- 24 Wave 4 MCP tools (70 total): ISO 20022 parsing, cross-border instruction checks, FX quote risk, SWIFT/bank transfer evidence, sanctions screening evidence assessment (caller-supplied), invoice match, payment compliance packet, Stellar/EVM/Core DAO settlement evidence, Pi payment evidence (attested/mock, no live API), bridge risk, DeFi position risk, Web3 signature evidence, stablecoin reserve evidence, robot mission receipt/evidence, machine SLA, loan application assessment, collateral packet verification, credit line utilization, escrow milestone verification, incident war room.
- 30 new skills (40 total) covering cross-border, chain evidence, DeFi, robot/machine, credit/loan, treasury ops, procurement, dispute evidence, and reconciliation workflows.

## Boundaries
- All Wave 4 tools are offline and deterministic over caller-supplied evidence.
- No live SWIFT, bank, PI Network, Stellar Horizon, EVM RPC, DeFi protocol, credit bureau, or regulator calls.
- `VERIFIED ≠ SAFE`. No settlement finality, sanctions clearance, KYC/AML approval, or compliance certification is claimed.
