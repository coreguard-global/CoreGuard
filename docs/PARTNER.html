Submitting opens a pre-filled request on GitHub in coreguard-global/.github — review it and press “Create”. Requests are public; for a private request use the private partner form.

What happens next
1

Your request is filed in the organization repository with the partnership label.

2

The founder reviews fit against the roadmap and evidence ceiling.

3

We reply on the thread with a scoped technical next step.

A request is not a partnership. CoreGuard lists no partner until both sides confirm in writing.
