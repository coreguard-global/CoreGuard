# CoreGuard Community & Contributor Program (Open Call)

Welcome to the CoreGuard community bounty and contributor program. We welcome high-impact contributions across integrations, verification DX, security correctness, ecosystem content, and CI/tooling.

## Bounty Tracks
1. **Integrations:** Stellar wallet integration examples, DEX integration examples, Soroban dApp adapters.
2. **Verification & DX:** Reviewer kit improvements, `--verify` runners, docs, tutorials (EN/AR), sample apps.
3. **Security & Correctness:** Fuzz/property tests for canonicalization/verifier, negative-case corpus, threat-model writeups.
4. **Ecosystem Content:** Technical deep-dives, demo videos/scripts, integration guides for partners.
5. **CI/Tooling:** Reproducibility, supply-chain hardening, developer ergonomics.

## Claim Process & Guidelines
- Comment on an open bounty issue indicating the track you want to pick up.
- Wait for maintainer scoping and approval before starting heavy development.
- Ensure all contributions pass CI checks and preserve state snapshot consistency.
